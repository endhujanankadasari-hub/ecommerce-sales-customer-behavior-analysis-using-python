# Visualizations

This folder contains charts generated for the E-Commerce Sales and Customer Behavior Analysis project.

## Charts included

- Missing values and data quality
- Quantity and unit price distributions
- Monthly sales and revenue trends
- Top-selling products by revenue and quantity
- Revenue by country
- Top customers by revenue
- Orders by weekday and hour
- Revenue distribution
- Quantity versus unit price
- Correlation heatmap
- Cancelled versus non-cancelled orders
- Customer segmentation using RFM analysis

All charts were generated using Python visualization libraries as part of the exploratory data analysis and business analysis.

## Purpose

These visualizations help identify sales trends, customer purchasing behavior, product performance, data quality issues, and potential business opportunities.
